#Critical #Remote Code Execution in #Drupal Core

On 18 November 2026 the Drupal Security Team released patches for a highly critical remote code execution #vulnerability in Drupal core, tracked as CVE-2026-132165 (SA-CORE-2026-017).

Under specific conditions, an unauthenticated #attacker can #abuse the core #installer (install.php) to attempt to reinstall an existing Drupal site. Successful exploitation can result in full site takeover or remote code execution.

Drupal warned that exploits could appear within hours or days. Reports indicate that #exploitation attempts against live sites began as early as 19 November 2026.
