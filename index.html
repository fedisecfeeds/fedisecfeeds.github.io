✨ Features and enhancements

ATT&CK for ICS is told apart from Enterprise. (#695)
  • Richer indicator metadata. Mandiant categories, campaigns, reports, and threat score, plus STIX 2.1 confidence, now reach Zeek intel. Google Threat Intelligence collections accept ioc_types and include_autogenerated_tags to cut memory use.

  • Smaller items: a low-RAM warning during configuration, a Hedgehog ISO prompt for the status kiosk, restyled account management pages, and Biomes dashboard docs in Analytics.
  • New Corelight Zeek detections: php2shell-detect and emudhra-weak-keys.

🛡️ Security remediation and hardening

  • Stored XSS in the file-upload container let a user with upload access run JavaScript in another user's session. The patch route also allowed writes to arbitrary directories. The read side is gone, the vulnerable handlers are stripped at build time, and responses carry nosniff and a strict CSP. (GHSA-qv8w-m37v-6c7j)
  • Credential disclosure in the hh-extracted-files proxy, which forwarded the caller's auth headers and cookies to a caller-chosen destination. Those headers are now cleared. (GHSA-325g-72fr-vj2x)
  • The published default Arkime WISE PIN and viewer password secret are removed. (GHSA-w2jh-h3pq-273j)
  • MaxMind and GitHub tokens are passed as BuildKit secrets instead of build arguments. Exposed MaxMind credentials were rotated. (GHSA-3293-9mf2-qf68)
  • Logstash's Beats input requires a client certificate when BEATS_SSL=true. (GHSA-f2gq-m4v3-2383)
  • The root-run PCAP upload watcher no longer follows symlinks. (GHSA-98jw-5wq7-6qjv)
  • Every outbound API request now has a timeout, and the API runs multiple workers, so one hung dependency can't take it down. (GHSA-x9f2-h2rj-vp63)
  • nginx/htpasswd and htadmin/metadata are tightened to 0640. (GHSA-rxpm-f8cm-2m5m)
  • The ISO install hook uses a private temp directory. (GHSA-wmrp-jr97-8xf4)
  • Nginx logs a warning when remote Keycloak runs without TLS verification. (GHSA-5wxm-fqf2-r23g)
  • /mapi/opensearch/ has role-based access control, with a read-only query tier and an admin tier.
  • /mapi/event records the submitter and namespaces caller IDs so they can't overwrite pipeline records. Config import is confined to the config directory (thanks @zaara2004). (#1147)
  • Supply chain: release binaries, source archives, web assets, Zeek packages, images, and GitHub Actions are pinned and checksum-verified. For hardened builds today, see the Iron Bank images. (#1138)
  • OpenResty 1.31.8.1 brings 12 nginx CVE fixes. lua-resty-openidc goes to 1.9.3 with a rewritten session config and a persisted NGINX_SESSION_SECRET.
  • PHP 8.4.27 in file-upload and htadmin addresses the php2shell vulnerabilities (CVE-2026-109618, CVE-2026-109619).

🐛 Bug fixes

  • Suricata rule metadata on uploaded PCAP: none of 33,303 sampled alerts carried it before. Instances are now warmed up and reloaded, so ET MITRE and CVE metadata map into threat.* and vulnerability.*. Scheduled rule updates now reload every socket. (#1262)

  • OpenSearch index retention no longer double-counts indices or rounds small ones to zero.

  • Full changelog: v26.09.0...v26.10.0

✨ Features and enhancements

  • Zeek 9.0.1 LTS. multicast_participants.log is parsed and shown in a new Multicast dashboard. ntp_control.log and ntp_private.log are parsed and indexed. (#1119)
  • OT field normalization. Zeek fields for BACnet, C12.22, DNP3, ENIP/CIP, Modbus, OPC UA, S7comm, and Synchrophasor are copied to Arkime's field names, so filters and drill-downs carry between Dashboards and Arkime. Original zeek.* fields are kept. (#1257)
  • Threat intel in ECS threat.* fields. Zeek intel kill chain phases, MISP MITRE galaxy tags, Mandiant and Google Threat Intelligence actors, Suricata ET mitre_* metadata, and capa results all map to normalized tactic, technique, subtechnique, and group fields. ATT&CK for ICS is told apart from Enterprise. (#695)
  • Richer indicator metadata. Mandiant categories, campaigns, reports, and threat score, plus STIX 2.1 confidence, now reach Zeek intel. Google Threat Intelligence collections accept ioc_types and include_autogenerated_tags to cut memory use.
  • Community ID in Logstash for Zeek logs that arrive without one, controlled by LOGSTASH_ZEEK_COMPUTE_COMMUNITY_ID (on by default). (#400)
  • API document lookup gains sort, offset, track_total_hits, and a total hit count. It and field aggregations now return shards and timed_out, so a partial or timed-out search no longer looks like an empty result. Bad arguments return HTTP 400. (#1130, #1131)
  • Custom ports for 13 ICSNPP analyzers through new ZEEK_PORTS_* variables. Three older variables are renamed to match, with values migrated on upgrade. (#1272)
  • NetBox skips the device-type library import once it has completed for a revision. NETBOX_DEVICETYPE_IMPORT_VENDORS can limit the first import, which also limits MAC OUI matching.
  • Smaller items: a low-RAM warning during configuration, a Hedgehog ISO prompt for the status kiosk, restyled account management pages, and Biomes dashboard docs in Analytics.
  • New Corelight Zeek detections: php2shell-detect and emudhra-weak-keys.

🛡️ Security remediation and hardening

  • Stored XSS in the file-upload container let a user with upload access run JavaScript in another user's session. The patch route also allowed writes to arbitrary directories. The read side is gone, the vulnerable handlers are stripped at build time, and responses carry nosniff and a strict CSP. (GHSA-qv8w-m37v-6c7j)
  • Credential disclosure in the hh-extracted-files proxy, which forwarded the caller's auth headers and cookies to a caller-chosen destination. Those headers are now cleared. (GHSA-325g-72fr-vj2x)
  • The published default Arkime WISE PIN and viewer password secret are removed. (GHSA-w2jh-h3pq-273j)
  • MaxMind and GitHub tokens are passed as BuildKit secrets instead of build arguments. Exposed MaxMind credentials were rotated. (GHSA-3293-9mf2-qf68)
  • Logstash's Beats input requires a client certificate when BEATS_SSL=true. (GHSA-f2gq-m4v3-2383)
  • The root-run PCAP upload watcher no longer follows symlinks. (GHSA-98jw-5wq7-6qjv)
  • Every outbound API request now has a timeout, and the API runs multiple workers, so one hung dependency can't take it down. (GHSA-x9f2-h2rj-vp63)
  • nginx/htpasswd and htadmin/metadata are tightened to 0640. (GHSA-rxpm-f8cm-2m5m)
  • The ISO install hook uses a private temp directory. (GHSA-wmrp-jr97-8xf4)
  • Nginx logs a warning when remote Keycloak runs without TLS verification. (GHSA-5wxm-fqf2-r23g)
  • /mapi/opensearch/ has role-based access control, with a read-only query tier and an admin tier.
  • /mapi/event records the submitter and namespaces caller IDs so they can't overwrite pipeline records. Config import is confined to the config directory (thanks @zaara2004). (#1147)
  • Supply chain: release binaries, source archives, web assets, Zeek packages, images, and GitHub Actions are pinned and checksum-verified. For hardened builds today, see the Iron Bank images. (#1138)
  • OpenResty 1.31.8.1 brings 12 nginx CVE fixes. lua-resty-openidc goes to 1.9.3 with a rewritten session config and a persisted NGINX_SESSION_SECRET.
  • PHP 8.4.27 in file-upload and htadmin addresses the php2shell vulnerabilities (CVE-2026-109618, CVE-2026-109619).

🐛 Bug fixes

  • Zeek intel on uploaded PCAP: packet processing now waits for intel files to load, so early packets and small captures get intel.log hits. (#1260)
  • Suricata rule metadata on uploaded PCAP: none of 33,303 sampled alerts carried it before. Instances are now warmed up and reloaded, so ET MITRE and CVE metadata map into threat.* and vulnerability.*. Scheduled rule updates now reload every socket. (#1262)
  • Workaround for an upstream OpenSearch Dashboards connection leak that crashed the container.
  • PCAP watchers no longer mistake read-only opens for activity, which had stalled or skipped files. (#1265)
  • STIX, TAXII, and MISP conversion: TAXII 2.1 feeds load, one bad object no longer drops a whole bundle, since is honored, and compound patterns are handled clause by clause.
  • Threat intel and API timestamps no longer shift with the host timezone. The /fields catalogue includes nested fields.
  • OpenSearch index retention no longer double-counts indices or rounds small ones to zero.
  • Other fixes cover PCAP upload duplicate detection, file scanning, Filebeat cleanup, NetBox enrichment, DTLS and MQTT transport labels, prune_files.sh, and the build and control scripts.
